# BerryScout — downloads

App **BerryScout by FarmUp** para Android (testadores).

**[⬇ Descarregar a versão mais recente](https://github.com/jpericao/berryscout-downloads/releases/latest/download/BerryScout.apk)**

1. Abre o link acima no telemóvel Android e descarrega o ficheiro.
2. Abre o ficheiro. Se o Android pedir, autoriza instalar apps desta origem (Definições → Permitir) e volta atrás → **Instalar**.
3. Abre a app e carrega em **Entrar com a Google**.

Só entram contas com acesso. Se ainda não tens, carrega em **Pedir acesso** na app.
